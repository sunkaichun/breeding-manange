# 养殖智能管理一体化项目 6 周实施执行计划

## 1. 项目概述

本项目基于现有《技术方案.md》，将“金蝶 ERP 数据自动同步、飞书多维表格建模、自动预警、移动端巡查闭环”落成一套可执行的 6 周项目实施计划。

项目面向养殖企业管理者、技术场长、IT 负责人和一线巡查人员，目标是把现有人工 Excel 报表升级为飞书多维表格中的实时数据驾驶舱，并通过飞书消息和任务表完成异常发现、责任分派、处理反馈和闭环追踪。

### 1.1 核心目标

1. 将现有人工 Excel 报表升级为自动化数据管理体系。
2. 打通金蝶 ERP 与飞书多维表格，实现批次、称重、领料等核心数据自动同步。
3. 建立养殖核心指标监控能力，包括体重异常、均匀度、料肉比、上市准确率、三对标、现场巡查。
4. 通过飞书消息和任务表实现异常预警、责任分派、处理反馈、闭环追踪。
5. 支持管理层、场长、技术员、巡查员在 PC 和移动端查看数据与处理任务。

### 1.2 实施范围

本次 6 周计划纳入：

- 飞书多维表格基础数据模型建设。
- 金蝶 ERP 数据同步方案落地。
- 基础公式、字段、视图、权限配置。
- 体重异常、均匀度、料肉比、上市预测等自动化规则配置。
- 移动端巡查入口与任务闭环。
- 试点场运行、培训、反馈优化、正式推广准备。

本次暂不纳入：

- 自研完整 App。
- 深度 AI 预测模型。
- 复杂成本核算系统。
- 金蝶 ERP 内部流程改造。
- 多区域大规模历史数据治理。

这些内容可作为二期或专项优化处理。

## 2. 实施原则

1. 先试点后推广：优先选择 1-2 个数据质量较好、业务配合度较高的养殖场试点。
2. 先数据准确再做复杂预警：字段口径、同步稳定性和计算准确性优先于高级图表和复杂模型。
3. 先核心闭环再高级指标：先跑通“数据同步 -> 异常识别 -> 消息通知 -> 任务闭环”，再扩展料肉比、三对标、上市预测等能力。
4. 飞书 Base 作为项目期统一工作台：项目问题、业务配置、异常处理和验收结果均围绕飞书多维表格沉淀。

## 5. 逐周执行计划

### 5.1 第 1 周：项目启动与环境准备

本周目标：完成项目启动、范围确认、环境开通和基础数据口径梳理，为后续同步与建模准备条件。

| 任务 | 负责人 | 交付物 | 验收标准 |
| --- | --- | --- | --- |
| 召开项目启动会，确认项目范围和试点场 | 项目负责人 | 启动会议纪要 | 范围、周期、试点对象确认 |
| 梳理现有 Excel 报表字段和业务口径 | 业务负责人 | 字段口径清单 | 每个核心字段有来源、含义、计算方式 |
| 获取金蝶 API 文档、测试账号、认证方式 | 金蝶顾问 | API 接口清单 | 至少明确批次、称重、领料 3 类数据接口 |
| 开通飞书多维表格、自动化、权限能力 | 飞书管理员 | 飞书环境清单 | 项目成员可访问并具备配置权限 |
| 创建空白 Base，搭建核心表结构草稿 | 实施工程师 | Base 初版结构 | 鸡群基础信息、称重记录、标准表、快照表、任务表创建完成 |

风险提示：如果金蝶 API 文档或账号在第 1 周无法提供，第 2 周同步任务会顺延。应提前确定 ERP 侧联系人和接口开通流程。

### 5.2 第 2 周：基础数据同步与字段映射

本周目标：跑通金蝶到飞书 Base 的基础同步链路，完成批次和称重记录的核心字段映射。

| 任务 | 负责人 | 交付物 | 验收标准 |
| --- | --- | --- | --- |
| 配置金蝶到飞书的数据同步链路 | 实施工程师/金蝶顾问 | 同步任务初版 | 可拉取测试数据并写入 Base |
| 完成批次基础信息字段映射 | 实施工程师 | 字段映射表 | 批次 ID、组织、品种、进苗日期、出栏日期等字段正确 |
| 完成称重记录字段映射 | 实施工程师 | 称重数据表 | 称重日期、均重、均匀度、存栏数可正常同步 |
| 设置同步频率与失败提醒 | 实施工程师 | 同步调度配置 | 基础信息每日同步，称重记录每 4 小时同步，失败可通知 |
| 抽样比对原始 Excel/金蝶数据 | 业务负责人 | 数据校验记录 | 抽样批次关键字段一致率达到项目验收标准 |

风险提示：金蝶字段与业务报表字段可能不一一对应。第 2 周应建立“金蝶字段 -> 业务口径 -> Base 字段”三列表，避免后续公式和预警基于错误字段建设。

### 5.3 第 3 周：Base 建模与基础计算

本周目标：完成标准表、公式字段、阶段快照和基础视图，让飞书 Base 能替代人工 Excel 的主要计算工作。

| 任务 | 负责人 | 交付物 | 验收标准 |
| --- | --- | --- | --- |
| 完成养殖标准对标表配置 | 业务负责人/实施工程师 | 标准表 | 品种、饲养组合、阶段、目标体重、均匀度阈值完整 |
| 配置日龄、阶段、目标值引用公式 | 实施工程师 | 公式字段 | 日龄阶段可自动判定，目标上下限可自动匹配 |
| 配置均重差异、达标状态、环比等字段 | 实施工程师 | 指标字段 | 核心计算结果与人工样例一致 |
| 建立阶段汇总快照逻辑 | 实施工程师 | 快照表/自动化规则 | 可按批次和阶段生成阶段末统计数据 |
| 完成基础视图 | 实施工程师 | 管理视图、异常视图 | 管理层可按批次、场区、阶段筛选查看 |

风险提示：养殖标准表如果维护不完整，目标值匹配会失败。第 3 周结束前应冻结首批试点品种和饲养组合的标准口径。

### 5.4 第 4 周：核心预警与任务闭环上线

本周目标：上线体重异常和均匀度两个核心预警场景，并形成飞书消息通知和巡查任务闭环。

| 任务 | 负责人 | 交付物 | 验收标准 |
| --- | --- | --- | --- |
| 配置体重异常预警规则 | 实施工程师/业务负责人 | 体重预警工作流 | 连续偏低达到阈值后自动推送消息 |
| 配置均匀度异常预警规则 | 实施工程师/业务负责人 | 均匀度工作流 | 低于阈值后自动生成异常提醒 |
| 建立巡查任务闭环表 | 实施工程师 | 任务表和任务视图 | 异常可自动生成任务，责任人可更新状态 |
| 配置飞书消息模板 | 飞书管理员/实施工程师 | 消息模板 | 消息包含批次、异常原因、处理入口 |
| 建立异常看板 | 实施工程师 | 异常任务看板 | 可查看待处理、处理中、已完成任务 |

风险提示：自动化规则过早做复杂会导致重复通知或漏发。第 4 周只开放体重异常和均匀度两个核心场景，确认稳定后再扩展。

### 5.5 第 5 周：高级场景与移动端巡查

本周目标：扩展料肉比、上市预测、三对标等高级场景，并配置移动端巡查页面和角色权限。

| 任务 | 负责人 | 交付物 | 验收标准 |
| --- | --- | --- | --- |
| 接入或维护领料数据 | 金蝶顾问/实施工程师 | 领料/料肉比数据表 | 可计算批次实时 FCR |
| 配置料肉比异常规则 | 实施工程师/业务负责人 | FCR 预警规则 | 超出目标阈值后可预警 |
| 配置上市前 7 天预测规则 | 实施工程师/业务负责人 | 上市预测视图 | 可输出预计均重、风险状态、建议处理 |
| 搭建三对标仪表盘 | 实施工程师 | 管理驾驶舱 | 市场、成本、质量指标可红黄绿展示 |
| 配置移动端巡查页面和权限 | 飞书管理员/实施工程师 | 应用模式页面 | 巡查员手机端可看负责批次、处理任务 |

风险提示：移动端权限配置错误会造成数据越权或任务不可见。第 5 周必须按角色、场区、批次负责人和任务责任人逐项验证权限。

### 5.6 第 6 周：试点验证、培训与上线切换

本周目标：完成试点运行、问题修复、用户培训和正式上线切换准备。

| 任务 | 负责人 | 交付物 | 验收标准 |
| --- | --- | --- | --- |
| 选择 1-2 个养殖场试点运行 | 项目负责人/业务负责人 | 试点运行记录 | 至少连续运行 3-5 个工作日 |
| 收集问题并调整阈值、字段、视图 | 实施工程师/业务负责人 | 优化清单 | 高优先级问题完成修复 |
| 开展用户培训 | 项目负责人/飞书管理员 | 培训材料 | 场长、技术员、巡查员能完成核心操作 |
| 输出试点验收报告 | 项目负责人 | 验收报告 | 数据准确性、预警有效性、使用反馈达标 |
| 制定正式上线切换方案 | 项目负责人 | 上线切换清单 | 明确 Excel 停用节奏、运维责任、后续支持机制 |

风险提示：第 6 周不建议直接硬停 Excel。应安排 1-2 周并行验证，逐步将飞书 Base 确认为主数据看板。

## 7. 验收标准

项目验收分为 6 类：

| 验收维度 | 验收标准 |
| --- | --- |
| 数据同步 | 批次基础信息、称重记录、领料记录可按计划同步；失败有提醒；关键字段可追溯来源 |
| 数据准确性 | 抽样批次与原 Excel/金蝶数据比对，核心字段和关键计算结果一致 |
| 指标计算 | 日龄阶段、目标体重、均重差异、达标状态、均匀度、FCR 等字段可自动计算 |
| 预警闭环 | 体重异常、均匀度异常至少两个核心场景能自动推送消息并创建任务 |
| 移动端使用 | 场长、技术员、巡查员可在手机端查看负责批次、接收预警、处理任务并回填结果 |
| 培训上线 | 试点用户完成培训，能独立完成核心操作；上线切换责任人与支持机制明确 |

## 8. 风险与应对

| 风险 | 影响 | 应对措施 |
| --- | --- | --- |
| 金蝶接口字段与业务报表字段不一致 | 数据无法直接映射，影响第 2-3 周进度 | 第 1 周做字段盘点会，建立“金蝶字段 -> 业务口径 -> Base 字段”三列表 |
| 金蝶接口限流或不稳定 | 同步延迟，预警不及时 | 采用增量同步、失败重试、失败消息告警；关键数据保留手工补录入口 |
| 称重数据缺失、0 值或异常值 | 错误触发预警或影响指标可信度 | 增加数据有效性规则，异常数据进入待确认视图，不直接参与预警 |
| 养殖标准表维护不完整 | 目标值匹配失败，计算字段为空 | 第 3 周前完成标准表冻结，缺失品种先用默认规则或标记“待维护” |
| 飞书自动化规则复杂度过高 | 后期难维护，出现重复消息或漏发 | 先上线体重、均匀度两个核心规则；高级规则第 5 周逐步开放 |
| 移动端权限配置错误 | 用户看到不该看的数据，或看不到任务 | 第 5 周做角色权限专项测试，按场区、批次负责人、任务责任人验证 |
| 用户仍依赖 Excel | 上线后使用率不足 | 第 6 周保留短期并行期，但明确 Excel 停用日期和数据唯一来源 |
| 试点数据量过小 | 预警规则无法充分验证 | 试点选择 1-2 个数据较完整场区，并补充历史称重数据回放验证 |

## 9. 上线切换安排

第 6 周后建议采用渐进式切换：

1. 并行 1-2 周：Excel 与飞书 Base 同步运行，重点核对数据口径。
2. 冻结 Excel 新增字段：避免业务继续扩展旧表。
3. 指定飞书为主数据看板：项目例会、异常处理、巡查任务只认飞书数据。
4. 到期停用人工汇总版 Excel：保留导出能力，但不再手工维护主报表。
